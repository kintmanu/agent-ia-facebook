# 🤖 Agent IA Facebook - Veille & Publication Automatique

Cet agent autonome recherche quotidiennement les tendances en Intelligence Artificielle, rédige un post engageant en français via Google Gemini, génère une image 3D futuriste avec Pollinations.ai et le publie automatiquement sur Facebook.

## 🚀 Fonctionnement
- **Planification :** Exécution automatique tous les matins à 9h00 UTC via GitHub Actions.
- **Modèle de texte :** Google Gemini Flash (100% gratuit).
- **Modèle d'image :** Pollinations.ai (100% gratuit).
- **Publication :** Meta Graph API.
